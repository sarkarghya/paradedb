# Release-maintenance handoff

Read `AGENT-HANDOFF.md` and `README.md` before preparing or archiving a release.
These files travel with `fork/` when `prepare-release.py` creates a new worktree.
Keep the destination's root agent instructions linked to this handoff; preserve any
upstream instructions already present there. Update the handoff's provenance and
validation snapshot when a new fork binary is actually released, not merely built.
